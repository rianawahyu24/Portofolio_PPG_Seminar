Taruh file foto di folder ini dengan nama persis seperti berikut,
maka foto akan otomatis muncul menggantikan placeholder di index.html:

- foto-riana.jpg          → foto profil Riana (identity panel)
- dosen-pembimbing.jpg    → foto Dosen Pembimbing
- guru-pamong.jpg         → foto Guru Pamong

Format JPG atau PNG sama-sama bisa dipakai — cukup ganti ekstensi
pada atribut src di index.html jika filenya .png.
Rasio foto disarankan persegi (1:1) agar pas dengan bingkai lingkaran/kotak.
